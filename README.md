# JinJuApp

在屏幕右下角（底部任务栏带内）常驻显示一行金句的 Windows 桌面小工具：每 3 分钟换一句，长句自动横向滚动，不打扰、不抢焦点、不写注册表（除非你主动开启自启动）。

v2.0.0 起为纯 Rust + Win32 原生实现（原为 Python/PyQt，见文末「为什么重写」）。

## 使用

1. 从 [Releases](https://github.com/Foam123/JinJuApp/releases) 下载 `JinJuApp.exe`，放入任意可写目录；
2. 双击运行：金句条出现在屏幕右下角的任务栏带上（通知区域左侧），托盘出现图标；
3. **换内容**：托盘右键 →「编辑金句」，或直接编辑 exe 旁的 `quotes.json`；
4. **换字体**：编辑 exe 旁的 `settings.json`（字体 / 字重 / 字号 / 颜色 / 不透明度），重启应用生效；
5. **开机自启动**：托盘右键 →「开机自启动」（默认关闭，由你决定）；
6. **退出**：托盘右键 →「退出」。

无需安装，无运行时依赖，约 250 KB。

## 金句数据

`quotes.json` 位于 exe 同目录，首次运行时自动导出内置的 451 条人民日报金句：

```json
[
  { "quote": "梦在前方，路在脚下。" },
  { "quote": "每一天都是新的开始。" }
]
```

- 改文件即改内容，**不需要重新下载程序**——英语单词、待办、座右铭，放什么都行；
- 文件损坏或语法错误时，弹窗给出具体行号与原因，本次回退内置金句运行，不会静默失败；
- 显示顺序为洗牌袋随机：每一轮 451 句全部出现且不重复，轮空后重新洗牌。

## 显示设置

`settings.json` 也在 exe 同目录，首次运行时导出默认值：

```json
{
  "font": "Microsoft YaHei UI",
  "weight": 400,
  "size": 11,
  "color": "auto",
  "opacity": 1
}
```

- `font`：GDI 字体名。常用可选：`Microsoft YaHei UI`（微软雅黑）、`SimHei`（黑体，笔画观感介于雅黑常规与粗体之间）、`SimSun`（宋体）、`KaiTi`（楷体）、`DengXian`（等线）；字体不存在时 GDI 自动回退，不会崩溃；
- `weight`：字重，`400` 常规、`700` 粗体（100–900）；字体家族缺该档位时由 GDI 就近选择；
- `size`：磅值（8–48），默认 11 pt——与任务栏自带文字（输入法「中/拼」、时钟）16 px 的字面高一致；
- `color`：文字颜色。`auto`（默认）**跟随任务栏浅色/深色模式**——浅色用 #000000、深色用 #FFFFFF，切换主题时自动更新；也可以写死为 `#RRGGBB` 或 `#RGB`；
- `opacity`：不透明度 `0.0–1.0`；
- 五个字段都可省略，缺省即上表默认值；文件语法错误或数值越界时，**启动弹窗说明原因**并回退默认值，不会静默失败。

**默认值就是照着任务栏自带文字调的**：输入法「中/拼」、时钟那些字是系统 UI 字体（中文回退到 Microsoft YaHei UI）Regular、16 px 字面高、纯黑不透明，所以默认取 Regular 11 pt / `#000000` / 不透明。差别只剩抗锯齿方式：任务栏用 ClearType（子像素）渲染，而本程序是逐像素透明分层窗口，只能用灰度抗锯齿，笔画会比任务栏略软约 1 px。

想要别的观感，改这一行即可：

- 更醒目：`{ "weight": 700, "size": 14, "color": "#1E1E1E", "opacity": 0.85 }`
- 更含蓄：`{ "weight": 400, "size": 10, "opacity": 0.9 }`
- 换字面：`"font": "SimHei"`（黑体）/ `"SimSun"`（宋体）/ `"KaiTi"`（楷体）/ `"DengXian"`（等线）

## 构建

```bash
cargo build --release        # 产物 target/release/JinJuApp.exe，约 250 KB
cargo test                   # 87 个单元测试
cargo clippy --all-targets -- -D warnings   # 零警告
powershell -File e2e.ps1     # 20 项端到端冒烟检查
```

要求：Rust 1.85+（edition 2024）与 Windows SDK（资源编译器，用于嵌入图标）。二进制只由 GitHub Actions 构建发布（tag 触发，附 SHA-256 校验和），仓库不跟踪任何可执行文件。

## 工程说明

- **模块**：`quotes`（数据加载/校验/兜底 + 洗牌袋 + xorshift）、`settings`（字体/字重/字号/颜色配置与校验）、`layout`（跑马灯状态机）、`geometry`（任务栏带/工作区几何与窗口放置）、`render`（灰度掩码 → 预乘 ARGB 纯函数 + GDI 宿主）、`startup`（opt-in 注册表自启动）、`tray`（托盘与菜单）、`win32`（手写 FFI——本程序对系统的全部调用集中在一个文件）；
- **FFI 决策**：有意不引入 windows-rs / winapi 等绑定库。本程序用到的 Win32 调用总量很小（六个系统 DLL），手写声明换来零第三方运行时依赖、单个文件即可整体审计、编译极快；代价（少量声明需自行维护、正确性靠人工核对文档）由单元测试与 E2E 覆盖；
- **渲染**：per-pixel-alpha 分层窗口，GDI 白字黑底获得逐像素覆盖度，再转为预乘 ARGB 上屏；**用 ClearType 子像素光栅化**（字形按像素网格 hinting，竖笔更实），再把 R/G/B 折算成单一覆盖率（亮度）——既拿到 ClearType 的锐利，又不会在透明底上留下彩边；实测同字号下墨量比纯灰度抗锯齿少约 12%，与任务栏原生 ClearType 文字只差约 5%（差在彩边本身，透明表面拿不到）；字体默认**微软雅黑（Microsoft YaHei UI）Regular 11 pt、纯黑不透明**——对齐任务栏自带文字的字面高与观感（此前沿用系统消息字体的 Light 300，中文细笔在壁纸上发虚；后来试过 Bold 14 pt，又比任务栏重），字体/字重/字号/颜色/不透明度都可在 `settings.json` 里改；
- **跑马灯**：窗口固定不动，只滚动文字，**文字长度不限**——静止 2 秒展示句首，向左匀速滑动到**句尾抵达显示区右缘即停**，停留 0.6 秒后原地淡出（250ms），于完全不可见处瞬移回句首再淡入（250ms），循环往复——复位跳变发生在 alpha=0 处，肉眼只见平滑的淡出复位，无擦回跳变；换句为 400ms 交叉淡化：旧句原地淡出、新句在静止位淡入。45 逻辑 px/s，随 DPI 缩放（对照原 Python 版语义，并消除了其擦回越冲+瞬移瑕疵）；
- **适配**：底部任务栏时金句条画在**任务栏带内**（按带高垂直居中），右边界停在**通知区域（`TrayNotifyWnd`）左侧**——它就是任务栏自带的一行字，不压上箭头、托盘图标和时钟；顶/侧边停靠或自动隐藏任务栏时改为浮在**工作区右下角**（工作区即桌面减去任务栏所占区域）；托盘图标增减会带动右边界，因此每次换句重新锚定一次（位置没变则不移动窗口）；装了 **TrafficMonitor** 时，会把它的任务栏窗口当作障碍物、在放得下的前提下整条往左让位，两个程序互不遮挡；DPI 变化时按新 DPI 重建度量与滚动器并重新锚定、explorer 重启（托盘自动恢复）、单实例互斥、`Win+D` 后在下一次换句时温和恢复显示（不做每秒对抗式自愈）；每 500ms 重申一次 z 序——其他窗口把任务栏抬到金句条之上（点图标、新开应用、飞窗）时约半秒内自动恢复；
- **测试边界**：全部决策逻辑为纯函数并以单元测试覆盖；窗口/GDI/注册表等系统交互由 `e2e.ps1` 做程序化端到端验证，不为 FFI 边界做 mock。

## 为什么从 Python 重写

原 Python/PyInstaller 版本（v1.0，已从主干移除，历史保留在 git）存在结构性问题：

| 问题 | 原版 | v2.0 |
|---|---|---|
| 体积 | 35.2 MB | 248.5 KB |
| 杀软误报 | PyInstaller bootloader + UPX 壳命中 Defender 机器学习「dropper」画像（[#1](https://github.com/31i45/JinJuApp/issues/1) 报 `Wacatac.C!ml`） | 纯静态原生代码，无 bootloader、无壳、无打包器 |
| 内容更新 | 数据焊死在 exe 内，改一个字要重新发版 | 外置 `quotes.json`，用户即改即生效 |
| 自启动 | 首次运行静默写注册表，无退出途径 | 默认关闭，托盘一键开关，可退出 |
| 错误处理 | 数据错误静默吞掉，只显示兜底句 | 错误弹窗直达用户，含原因与修复路径 |
| 可测性 | 纯逻辑焊死在 QWidget 中，0 测试 | 87 单元测试 + 20 项 E2E，全绿 |
